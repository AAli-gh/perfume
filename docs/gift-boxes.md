# باکس هدیه و بسته‌بندی سفارش

مشتری می‌تواند باکس هدیه را **جدا** بخرد، یا هنگام ثبت سفارش **باکس انتخاب کند** و بگوید عطرها داخل باکس چیده شوند، باکس جدا ارسال شود یا با متن دلخواه توضیح دهد چطور بسته‌بندی شود.

## ۱. تعریف باکس هدیه (پنل مدیریت ← محصولات)

باکس هدیه یک محصول معمولی با **نوع محصول = باکس هدیه** است، پس قیمت، موجودی، دفتر موجودی، سفارش‌ها و گزارش فروش برایش مثل عطر کار می‌کند.

| فیلد | توضیح |
|---|---|
| نوع محصول | «باکس هدیه» |
| گنجایش باکس | چند شیشه عطر در آن جا می‌شود (الزامی برای باکس) |
| خانواده رایحه | برای باکس لازم نیست |
| حجم‌ها | یک ردیف با حجم ۰ و قیمت و موجودی باکس؛ اگر چند اندازه یا رنگ دارید، برای هر کدام یک محصول جدا بسازید تا گنجایش هر کدام درست باشد |

- **کجا دیده می‌شود:** صفحه `/gift-boxes/` (لینک «باکس‌های هدیه» در فوتر)، جستجوی سایت، بخش «در باکس هدیه بفرستید» در صفحه هر عطر، و بخش اختیاری «باکس‌های هدیه» در سازنده صفحه اصلی.
- **کجا دیده نمی‌شود:** فهرست و فیلترهای فروشگاه (بدون جستجو)، پرفروش‌ها، مقایسه، پیشنهاد سلیقه‌محور و عطریاب؛ این‌ها فقط عطرها را نشان می‌دهند.
- داده نمونه (`seed_demo`) سه باکس می‌سازد: کلاسیک (۱ عطر)، دوتایی مخملی (۲ عطر) و سلطنتی (۳ عطر).

## ۲. انتخاب مشتری در صفحه تسویه

بخش **«بسته‌بندی و هدیه»** در فرم ثبت سفارش:

| گزینه | شرط | نتیجه |
|---|---|---|
| بسته‌بندی معمولی | — | پیش‌فرض؛ جزئیات هدیه پنهان است |
| عطرها داخل باکس هدیه چیده شوند | سفارش عطر و باکس داشته باشد و گنجایش باکس‌ها ≥ تعداد عطرها | — |
| باکس هدیه جدا ارسال شود | باکس داشته باشد | باکس بدون چیدن، کنار سفارش |
| توضیح می‌دهم | متن توضیح الزامی است (تا ۵۰۰ نویسه) | مثلاً «دو عطر داخل باکس، یکی جدا؛ روبان قرمز» |

- **انتخاب باکس:** اگر مشتری باکس را از قبل به سبد اضافه نکرده باشد، فهرست باکس‌های موجود با تصویر، گنجایش و قیمت نمایش داده می‌شود. باکس انتخاب‌شده یک قلم به سفارش اضافه می‌کند، موجودی‌اش رزرو می‌شود و خلاصه سفارش و مبلغ بلافاصله (HTMX) به‌روز می‌شود.
- **باکس داخل سبد:** اگر باکس در سبد است، همان استفاده می‌شود و فقط خلاصه «باکس در سبد شما: … با گنجایش …» نشان داده می‌شود.
- **پیام کارت هدیه** (تا ۳۰۰ نویسه)، **از طرف** و **«فاکتور قیمت داخل بسته نباشد»** برای هر سه گزینه هدیه در دسترس‌اند.
- **خطاهای روشن:** «یک باکس هدیه انتخاب کنید»، «گنجایش باکس‌ها ۲ شیشه است ولی سفارش شما ۳ عطر دارد…» یا «سفارش شما عطری ندارد که داخل باکس چیده شود».
- باکسی که با «بسته‌بندی معمولی» علامت خورده باشد به سفارش اضافه نمی‌شود.

## ۳. پس از ثبت

- **پنل مدیریت ← سفارش‌ها:** بخش «بسته‌بندی هدیه» داخل هر سفارش، و فیلتر «بسته‌بندی» در فهرست برای پیدا کردن سفارش‌هایی که باید کادو شوند.
- **صفحه سفارش مشتری و ایمیل سفارش:** نوع بسته‌بندی، توضیح، متن کارت و «از طرف» نمایش داده می‌شود.

## برای توسعه‌دهنده

| بخش | کد |
|---|---|
| نوع محصول و گنجایش | `Product.kind`، `Product.gift_capacity` (`apps/catalog/profile.py: Kind`)؛ `Product.objects.perfumes()` / `.gift_boxes()` |
| فهرست باکس‌ها | `apps/catalog/selectors.py: gift_boxes, gift_box_variants`؛ صفحه `catalog:gift_boxes` |
| قواعد بسته‌بندی | `apps/orders/packaging.py` (`contents`، `validate`) |
| فرم و ثبت سفارش | `CheckoutForm` (فیلدهای `packaging`، `gift_box`، …) و `create_order` که باکس انتخابی را به اقلام و رزرو موجودی اضافه می‌کند |
| پیش‌نمایش قیمت | `Cart.quote(..., extra=[...])` و `orders.views._quote_context` |
| قالب | `themes/base/templates/orders/partials/gift_packaging.html`؛ نمایش/پنهان‌سازی بخش‌ها فقط با CSS `:has()` (`.gift-panel` در `static/src/input.css`) |
| تست‌ها | `apps/orders/tests/test_gift_packaging.py` و E2E `test_gift_box_packaging_at_checkout` |
