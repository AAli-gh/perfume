# ADR-0004: Design Token‌ها به‌صورت CSS Variables، بدون build دوباره CSS

**وضعیت:** پذیرفته‌شده

## زمینه
مدیر فروشگاه باید رنگ و فونت را از استودیو تغییر دهد. اگر هر تغییر نیاز به build دوباره Tailwind داشت، این کار در production ممکن نبود.

## تصمیم
- توکن‌ها (`apps/themes/tokens.py`) به این ترتیب ترکیب می‌شوند: `DEFAULT_TOKENS` ← پیش‌تنظیم ← `overrides` فروشگاه.
- `{% theme_head %}` آن‌ها را به `<style nonce>` با متغیرهای `:root` تبدیل می‌کند. رنگ‌ها به‌صورت کانال RGB نوشته می‌شوند تا `bg-primary/20` در Tailwind کار کند.
- گونه‌های کامپوننت با `data-*` روی `<html>` تعیین می‌شوند.
- ورودی‌ها سخت‌گیرانه اعتبارسنجی می‌شوند: hex، فهرست مجاز فونت، بازه عددی و گزینه‌های مشخص. پس تزریق CSS ممکن نیست.
- فقط تفاوت با پیش‌تنظیم ذخیره می‌شود.

## پیامدها
- تغییر ظاهر فوری است و CSS ساخته‌شده برای همه فروشگاه‌ها یکی است.
- رنگ ثابت در CSS ممنوع است و تست `test_built_css_has_no_hardcoded_store_colors` آن را بررسی می‌کند.
- کنتراست پیش‌تنظیم‌ها با تست WCAG AA کنترل می‌شود. رنگ‌های دلخواه مدیر کنترل کنتراست ندارند (کار آینده: هشدار در استودیو).
