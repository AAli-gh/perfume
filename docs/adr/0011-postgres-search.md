# ADR-0011: جستجو با PostgreSQL به‌جای Elasticsearch

**وضعیت:** پذیرفته‌شده

## زمینه
جستجوی فارسی باید ي/ك عربی، نیم‌فاصله و ارقام فارسی را یکسان بداند و حین تایپ کار کند. Elasticsearch در brief کنار گذاشته شده است.

## تصمیم
- full-text وزن‌دار PostgreSQL روی یک ستون `search_vector`، به‌علاوه `pg_trgm` برای شباهت.
- نرمال‌سازی فارسی در `apps/catalog/search.py`، هم روی متن ایندکس و هم روی عبارت جستجو.
- ایندکس با signal و task به‌روز می‌شود.

## پیامدها
- سرویس اضافه‌ای لازم نیست و جستجو در تراکنش و تست‌ها حاضر است.
- برای چند ده هزار محصول کافی است. اگر کاتالوگ خیلی بزرگ شد یا نیاز به faceting پیشرفته بود، باید بازنگری شود.
