# ADR-0007: HTMX و Django Templates به‌جای SPA

**وضعیت:** پذیرفته‌شده

## زمینه
فروشگاه باید سریع، سئوپذیر و قابل نگهداری توسط یک تیم Django باشد. React و Vue در brief کنار گذاشته شده‌اند.

## تصمیم
- همه صفحه‌ها در سرور رندر می‌شوند. HTMX 2 فقط بخش‌ها را جایگزین می‌کند: فیلترها، سبد، فرم‌ها و ویرایشگر استودیو.
- view با `request.htmx` تصمیم می‌گیرد partial برگرداند یا صفحه کامل. به‌روزرسانی‌های جانبی (شمارنده سبد، اعلان) out-of-band ارسال می‌شوند.
- هر فرم بدون JS هم کار می‌کند.
- HTMX با `allowEval:false` و `allowScriptTags:false` پیکربندی شده است تا با CSP سازگار باشد.
- JS اختصاصی کم و در `static/js/` است. رفتارها با `data-*` تعریف می‌شوند.

## پیامدها
- سئو و اولین نمایش صفحه بدون SSR جداگانه.
- تعاملات پیچیده‌تر (مثل کشیدن و رها کردن در استودیو) JS دستی لازم دارند. این کد کم است و با تست E2E پوشش داده شده است.
