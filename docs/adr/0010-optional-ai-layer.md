# ADR-0010: لایه AI اختیاری، جدا از هسته، با تأیید انسانی

**وضعیت:** پذیرفته‌شده

## زمینه
brief پروژه قابلیت‌های AI را برای آینده خواسته است: تولید توضیح محصول، سئو و پیشنهاد چیدمان. هزینه، تأخیر و خطای مدل‌ها نباید فروشگاه را از کار بیندازد.

## تصمیم
- `apps/ai` یک رابط `AIProvider` دارد که با `AI_PROVIDER` انتخاب می‌شود. پیش‌فرض `NullProvider` است و AI خاموش است.
- هسته هرگز `apps.ai` را import نمی‌کند (با تست معماری قفل شده است).
- خروجی AI همیشه پیش‌نویس است. ذخیره و انتشار با تأیید انسان انجام می‌شود، از همان مسیر پیش‌نویس و انتشار استودیو یا پنل.
- فراخوانی‌ها در Celery task یا admin action انجام می‌شوند، نه در چرخه درخواست مشتری.
- کلیدها فقط از متغیر محیطی خوانده می‌شوند.

## پیامدها
- قطع سرویس AI روی فروش اثری ندارد.
- قابلیت‌ها هنوز پیاده نشده‌اند و فقط اسکلت و قرارداد آماده است ([roadmap](../roadmap.md)).
