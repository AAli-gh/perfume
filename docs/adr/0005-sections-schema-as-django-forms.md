# ADR-0005: بخش‌های صفحه: JSON با schema فرم Django و registry

**وضعیت:** پذیرفته‌شده

## زمینه
صفحه اصلی باید از بخش‌های قابل جابه‌جایی ساخته شود. تنظیمات بخش‌ها ساختار متفاوت دارند و از ورودی کاربر می‌آیند.

## تصمیم
- `PageSection.settings` یک فیلد JSON است. schema هر نوع، یک `forms.Form` است: اعتبارسنجی، پیش‌فرض‌ها و فرم ویرایش استودیو همه از همین ساخته می‌شوند.
- انواع بخش با `@register` در registry ثبت می‌شوند. داده را از selectorها می‌گیرند و قالبشان در لایه پوسته است.
- اگر یک بخش هنگام رندر خطا بدهد، فقط همان بخش حذف و لاگ می‌شود.
- همین الگو برای هدر و فوتر هم استفاده شده است (`apps/themes/chrome.py`، `ListOfDictsField`).

## پیامدها
- نوع بخش جدید بدون migration اضافه می‌شود.
- JSON در دیتابیس قید ساختاری ندارد، پس داده قدیمی هنگام خواندن با فرم دوباره اعتبارسنجی و با پیش‌فرض‌ها تکمیل می‌شود.
