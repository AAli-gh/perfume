# ADR-0008: ماندن روی Tailwind CSS 3

**وضعیت:** پذیرفته‌شده

## زمینه
در فاز ۱۲ ارتقا به Tailwind 4 بررسی شد.

## تصمیم
روی Tailwind 3.4 بمانیم.
- Tailwind 4 پشتیبانی از Safari پیش از 16.4 و Chrome پیش از 111 را حذف می‌کند. سهم این مرورگرها در مخاطبان ایرانی (دستگاه‌های قدیمی‌تر) ناچیز نیست.
- هشدار امنیتی `braces` فقط به ابزار ساخت مربوط است و وارد image نهایی نمی‌شود. `npm audit --omit=dev` صفر مورد گزارش می‌کند.
- نقشه رنگ‌ها به CSS Variables در `tailwind.config.js` با نسخه 3 کامل کار می‌کند.

## پیامدها
- وقتی سهم مرورگرهای قدیمی کم شد، ارتقا دوباره بررسی شود. برای ارتقا، پیکربندی باید به `@theme` در CSS منتقل شود و ۱۸ اسکرین‌شات مرجع پیکسل‌به‌پیکسل مقایسه شوند.
