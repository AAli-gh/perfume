# جستجوی هوشمند

مشتری هر طور که حرف می‌زند می‌نویسد، مثلاً «عطر خنک زیر سه تومن» یا «زنانه شیرین برای شب بدون عود». سایت عبارت را به فیلترهای دقیق تبدیل می‌کند و همان عطرها را نشان می‌دهد. این قابلیت بدون سرویس خارجی، بدون AI و بدون هزینه کار می‌کند.

## چه چیزهایی را می‌فهمد

| معیار | نمونه‌ها | فیلتر |
|---|---|---|
| قیمت | «زیر سه تومن»، «کمتر از ۲٫۵ میلیون»، «بین ۴ تا ۶ میلیون»، «از ۵ میلیون به بالا»، «حدود ۴ میلیون»، «۵۰۰ هزار تومنی»، «سه میلیون و پانصد هزار» | دست‌کم یکی از حجم‌های عطر در این بازه باشد. «حدود» یعنی ±۲۰٪. |
| حس رایحه | خنک، تازه، اسپرت، مرکباتی، دریایی، گرم، شیرین، گلی، چوبی، شرقی، تند و ادویه‌ای، دودی | خانواده رایحه متناظر در فروشگاه شما؛ اگر چنین خانواده‌ای نباشد، نت‌های شاخص آن حس |
| نت | «وانیل»، «عطر وانیلی»، «کهربایی»، «زعفرونی» | عطرهایی که این نت را دارند |
| بدون… | «بدون عود»، «بدون عود و چرم»، «نه شیرین»، «غیر از گلی» | حذف عطرهای دارای آن نت یا حس |
| برند، دسته، برچسب | نام‌هایی که در پنل تعریف کرده‌اید | همان برند، دسته (با زیرشاخه‌ها) یا برچسب |
| جنسیت | مردانه، مردونه، آقایان، زنانه، خانم، برای مامانم، یونیسکس | مردانه: مردانه و یونیسکس (مردانه اول) |
| فصل | تابستونی، هوای گرم، زمستانی، بهاری، پاییزی | فصل مناسب |
| موقعیت | روزانه، اداری، محل کار، مهمونی، شب، مجلسی، عروسی، قرار عاشقانه | موقعیت مناسب |
| ماندگاری و پخش بو | ماندگار، خیلی ماندگار، پرپخش، قوی، ملایم، لایت | ماندگاری ۴ یا ۵ به بالا؛ پخش بو ۴ به بالا یا ۳ به پایین |
| غلظت | ادو پرفیوم، ادو تویلت، اکستریت، ادو کلن | غلظت |
| حجم | «۱۰۰ میل»، «50ml» | همان حجم؛ اگر قیمت هم گفته شود، قیمت همان حجم بررسی می‌شود |
| ترتیب | ارزون، ارزان‌ترین، گران‌ترین، جدیدترین، محبوب‌ترین، پرفروش | مرتب‌سازی (مرتب‌سازی انتخابی صفحه اولویت دارد) |
| دیگر | «موجود»، «باکس هدیه» | فقط موجود؛ فقط باکس‌های هدیه |

### زبان محاوره، اعداد و اشتباه تایپی

- **اعداد:** عدد با رقم فارسی یا لاتین (۳، 3.5، ۳٫۵، 3,500,000) یا با حروف (سه، دو و نیم، سیصد و پنجاه) نوشته شود.
- **واحد پول:** میلیون، هزار، تومان، تومن یا ریال. اگر واحد گفته نشود («زیر ۳»)، از روی بازه قیمت محصولات فروشگاه حدس زده می‌شود: «سه تومن» یعنی ۳ میلیون و «زیر ۵۰۰» یعنی ۵۰۰ هزار.
- **محاوره:** «زمستون»، «مردونه»، «زعفرون» و نوشتن ي/ك عربی یا نیم‌فاصله مشکلی ایجاد نمی‌کند.
- **اشتباه تایپی:** نزدیک‌ترین نام نت، برند یا خانواده فروشگاه جایگزین می‌شود و پیام «اصلاح املایی: «زعفرن» ← «زعفران»» نمایش داده می‌شود.
- **کلمات بی‌معنی:** کلمه‌ای که در هیچ عطری پیدا نشود، جستجو را خالی نمی‌کند. در نظر گرفته نمی‌شود و به مشتری گفته می‌شود.
- **نام محصول یا برند:** اگر عبارت نام یک محصول یا برند باشد (مثلاً «شب کهربایی»)، جستجوی متنی معمولی انجام می‌شود، نه برداشت «شب» و «کهربا».
- **یک کلمه تنها** (مثلاً «مشک» یا «خنک»): جستجوی متنی معمولی، که نتیجه کامل‌تری دارد (مثلاً «مشک سفید» را هم پیدا می‌کند). اگر جستجوی متنی چیزی پیدا نکند، از فیلتر استفاده می‌شود.

## اگر نتیجه دقیقی نبود

سایت صفحه خالی نشان نمی‌دهد. کم‌اهمیت‌ترین شرط‌ها را یکی‌یکی کنار می‌گذارد تا به نزدیک‌ترین نتیجه برسد و پیامی نمایش می‌دهد، مثلاً: «عطری دقیقاً با همه این شرط‌ها پیدا نشد؛ نزدیک‌ترین گزینه‌ها بدون شرط «قیمت تا ۳ میلیون تومان»». برچسب شرط کنار گذاشته‌شده خط می‌خورد.

- **ترتیب کنار گذاشتن:** کلمات آزاد ← موجودی ← موقعیت ← فصل ← پخش بو ← ماندگاری ← غلظت ← حجم ← نت ← برند ← **قیمت** ← جنسیت ← حس و خانواده رایحه
- **چرا قیمت قبل از نوع رایحه:** «عطر خنک کمی گران‌تر» به خواسته مشتری نزدیک‌تر است تا «عطر غیرخنک ارزان». وقتی قیمت کنار گذاشته شود، نتایج از نزدیک‌ترین قیمت مرتب می‌شوند.

## رابط کاربری

- **پنل جستجوی هدر:** حین تایپ، برداشت سایت از عبارت و ۵ نتیجه اول نمایش داده می‌شود (HTMX). اگر چیزی تایپ نشده باشد، نمونه‌جستجوها نمایش داده می‌شوند.
- **صفحه فروشگاه:** کادر جستجوی هوشمند بالای نتایج. همچنین نوار «برداشت ما از جستجوی شما» با یک برچسب برای هر شرط. ✕ روی هر برچسب همان جستجو را بدون آن شرط تکرار می‌کند.
- **ترکیب با فیلترها:** فیلترهای کناری (برند، قیمت، نوع رایحه) با جستجو ترکیب می‌شوند.

## برای دقیق‌تر شدن نتایج (مدیر فروشگاه)

- **مشخصات رایحه** هر محصول را کامل کنید: جنسیت، فصل، موقعیت، ماندگاری، پخش بو و غلظت (پنل مدیریت ← محصول). محصولی که مشخصه‌ای را خالی گذاشته حذف نمی‌شود، ولی بعد از محصولات با تطبیق قطعی نمایش داده می‌شود.
- **هرم نت‌ها و خانواده رایحه** هر محصول پایه حس‌ها («خنک»، «شیرین») و «بدون…» است.
- **نام‌های خودتان:** هر برند، دسته، برچسب، نت یا خانواده‌ای که در پنل تعریف کنید، بلافاصله قابل جستجو است (واژگان حداکثر ۱۰ دقیقه کش می‌شود و با هر تغییر پاک می‌شود).

## برای توسعه‌دهنده

| بخش | کد |
|---|---|
| تجزیه عبارت | `apps/catalog/smart_search.py: parse()`: توکن‌سازی، بلندترین تطبیق در واژه‌نامه، اعداد و پول، نفی، اصلاح املایی |
| واژگان ثابت | بالای همان فایل: `FEELS`، `GENDER_WORDS`، `SEASON_WORDS`، `OCCASION_WORDS`، `SORT_WORDS`، `STOPWORDS`، … |
| واژگان فروشگاه | `load_vocab()`: کش به ازای فروشگاه؛ `invalidate_vocab` در `apps/catalog/signals.py` |
| اعمال فیلتر | `apply()`؛ قیمت، حجم و موجودی با یک `Exists` روی یک حجم مشترک؛ `profile_rank` برای مشخصات خالی |
| کنار گذاشتن شرط‌ها | `relax()` و `RELAX_ORDER` |
| فروشگاه | `selectors.search_shop()` (و `filter_products` که از آن استفاده می‌کند)؛ `views._search_context` و `views.search_suggest` |
| قالب‌ها | `catalog/partials/smart_query.html`، `search_suggest.html`، `search_examples.html` |
| ایندکس | سند جستجو مشخصات رایحه («زنانه»، «تابستان») را هم دارد. بعد از به‌روزرسانی: `python manage.py reindex_search` |
| تست‌ها | `apps/catalog/tests/test_smart_search.py` و E2E `test_smart_search_live_suggestions_and_chips` |

برای افزودن واژه یا حس جدید، کافی است به فهرست مربوط اضافه کنید و یک ردیف به `test_parse` بیفزایید. روی PostgreSQL و SQLite (نسخه نمایشی) یکسان کار می‌کند.
